A shared mailbox, such as a department inbox, shows up in Outlook once you have access, and you can add it yourself if it does not appear.

To get access, submit an Access Request in the IT Self-Service Portal at itportal.contoso-health.example and name the shared mailbox. The mailbox owner approves the request, and you get an email when access is granted.

In classic Outlook for Windows, the mailbox usually appears in your folder list on its own within an hour. Restart Outlook if it has not. If it still does not show:

1. Select File, then Account Settings, then Account Settings again.
2. Select your email account, then Change, then More Settings.
3. On the Advanced tab, select Add, type the shared mailbox name, and select OK.
4. Select Apply and OK, close the windows, and restart Outlook.

In the new Outlook and in Outlook on the web, right-click Shared with me or Folders, select Add shared folder or mailbox, type the mailbox name, and select Add.

In Outlook for Mac, select Tools, then Accounts, then Delegation and Sharing. On the Shared With Me tab, select the plus sign, type the mailbox name, and select Add.

To send from the shared mailbox, start a new message, select From, and choose the shared address. If you do not see the From field, turn it on in the Options tab. If you get an error saying you do not have permission to send as that mailbox, submit another Access Request asking for Send As permission.

Messages you send from a shared mailbox are saved in that mailbox's Sent Items, so your coworkers can see them.
