Use Cisco AnyConnect to connect to the Contoso Health VPN when you work from home or travel and need internal systems such as shared drives or Remote Desktop to your office PC.

Cisco AnyConnect comes installed on every Contoso Health laptop. Look for the AnyConnect icon in the Windows system tray near the clock, or in the Mac menu bar.

1. Connect to the internet first, for example on your home Wi-Fi.
2. Open Cisco AnyConnect Secure Mobility Client.
3. In the connection box, type vpn.contoso-health.example and select Connect.
4. Enter your Contoso Health username and password and select OK.
5. A text message with a one-time code is sent to the mobile phone number on your account. Type the code in the Second Password box and select Continue. The code works once and expires after a few minutes.
6. Read the acceptable use banner and select Accept. When the AnyConnect icon shows a small padlock, you are connected.
7. When you finish working, open AnyConnect and select Disconnect.

You only type the server address the first time. After that, AnyConnect remembers vpn.contoso-health.example, so you just select Connect.

If the text message does not arrive within a minute, select Cancel and connect again to get a new code. Make sure your phone has signal and that the mobile number on your account is current.

If AnyConnect says the connection attempt has failed, check that you typed vpn.contoso-health.example exactly, then restart your laptop and try again. Hotel and airport Wi-Fi often makes you accept terms in a web browser before the VPN can connect.

Never share your code. The service desk will never ask for your password or for a code you did not request.
