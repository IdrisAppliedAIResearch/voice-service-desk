Accounts for new employees are created automatically from the HR onboarding record, 5 business days before the start date.

How it works:
1. After the offer is accepted, HR enters the new hire in the HR onboarding system with their start date, department, manager, and a personal email address.
2. Five business days before the start date, the network account and mailbox are created. The username is the first initial followed by the last name, with a number added if that username is taken. The email address is first.last@contoso-health.example.
3. The manager gets an email with the new hire's username and email address.
4. On the first day, the new hire signs in at the IT Bar on the first floor of Building A, Main Campus, or with a one-time setup link sent to the personal email address they gave HR. They enroll in multi-factor authentication that same day.

What managers should do before day one, as soon as the account exists:
1. Request any software the role needs with Request Software in the IT Self-Service Portal at itportal.contoso-health.example.
2. Request shared drive folders with an Access Request. The data owner of each folder approves it.
3. Request door and room access with Badge Access. The manager and the area owner both approve it.
Approvals take time, so submit these early. Requests made on the first day may not be ready until later that week.

If the account was not created:
The service desk cannot create an employee account by hand, because every account must match an HR record. If the start date is close and the account is missing, the manager should ask HR to confirm that the onboarding record is complete and the start date is right. When a start date moves, HR updates the record and account creation moves with it.

The setup link is for the new hire only. Nobody from Contoso Health will ask them to share it.

Still stuck? Call the service desk at extension 4357 (H E L P) or 555-0100 with the new hire's name and start date.
